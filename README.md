Welcome to the **Official Portfolio Website** repository. This project is a modern, high-performance web application designed to showcase my professional journey, technical skills, and creative projects. Built with the latest web technologies, it delivers a premium user experience with smooth animations, responsive design, and a sleek dark-themed aesthetic.

---

## 🚀 Key Features

*   **✨ Dynamic Hero Section**: visually engaging introduction with abstract design elements.
*   **🎨 Modern UI/UX**: Crafted with **Tailwind CSS v4** and **Radix UI** for accessible, beautiful components.
*   **⚡ Smooth Animations**: Powered by **Framer Motion** and **Lottie**, ensuring every interaction feels alive.
*   **🛠️ Skills & Tools**: Interactive showcase of my technical expertise.
*   **📂 Project Gallery**: detailed views of my works (AI/ML, Full Stack, etc.) with GitHub links.
*   **📊 GitHub Contributions**: Integrated activity calendar to track my coding streak.
*   **📱 Fully Responsive**: Optimized for all devices, from desktops to mobile phones.
*   **📝 Contact & Connections**: Easy ways to reach out for collaborations.

---

## 🛠️ Tech Stack

This project is built using the bleeding edge of the React ecosystem:

*   **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
*   **Library**: [React 19](https://react.dev/)
*   **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
*   **Animations**: [Framer Motion](https://www.framer.com/motion/), [Lottie React](https://lottiefiles.com/)
*   **Icons**: [Lucide React](https://lucide.dev/), [React Icons](https://react-icons.github.io/react-icons/)
*   **Utilities**: `clsx`, `tailwind-merge`

## 🏗️ Getting Started

To run this project locally for viewing purposes:

1.  **Clone the repository** (Note: See usage policy below)
    ```bash
    git clone https://github.com/AryanDhamale/MY_WEBSITE.git
    cd MY_WEBSITE_GITHUB
    ```

2.  **Install dependencies**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

4.  **Open in Browser**
    Visit [http://localhost:3000](http://localhost:3000) to view the site.
